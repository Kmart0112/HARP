# 馬券判断への接続

## 目的

HARP では、モデルが出した確率をそのまま買い目にしない。確率予測、オッズ、市場の歪み、資金配分、買わない判断を分けて扱う。

## 基本構造

1. モデルで勝率・複勝率などの確率を推定する。
2. 校正を確認し、確率として使えるかを見る。
3. オッズから期待値や edge を計算する。
4. bankroll とリスク制約を入れる。
5. no-bet を含めて判断する。

予測性能が良いことと、実際に買って利益が出ることは同じではない。特に確率の過信、低オッズの過大評価、サンプルの偏りには注意する。

## 見るべき指標

- 予測側: AUC、LogLoss、Brier、校正曲線
- 市場側: implied probability、edge、期待値
- 投資側: 回収率、ドローダウン、ベット数、的中率、資金曲線
- 運用側: 買わない判断の頻度、レース条件別の安定性

## 注意点

ROI は分散が大きく、短い期間では判断がぶれやすい。特徴量採否では、まず確率モデルとして壊れていないかを見て、その後に馬券条件へ進める。

買い方最適化の一般原則は [../knowledge/foundations/betting_optimization_principles.md](../knowledge/foundations/betting_optimization_principles.md) にまとめる。
