# 共通意思決定フレーム

feature/model/betting で共通して使う、  
「何を根拠に採用判断するか」の最小フレーム。

## 1. 問いを固定する
- 何を改善したいか（指標・運用上の課題）を1文で定義する。
- 改善対象のスコープ（期間・市場・レース条件）を固定する。

## 2. 比較対象を固定する
- baseline を先に固定し、比較粒度を揃える。
- 指標は最低2軸以上で判断する（性能 + 安定性）。

## 3. トレードオフを明示する
- 改善したもの:
- 悪化したもの:
- 許容範囲:

## 4. 判断を3値化する
- 採用:
  - 実務で有意な改善があり、運用リスクが許容内。
- 保留:
  - 効果はあるが、追加検証が必要。
- 不採用:
  - 効果不足、再現性不足、または運用上の不整合あり。

## 5. 反証条件を残す
- どの条件になれば判断を覆すかを先に書く。
- 見直しタイミング（定期/イベント駆動）を決める。

## 6. 記録原則
- 事実（計測値）と解釈（判断理由）を分けて書く。
- 1判断に1根拠ID（run_id）を紐づける。
