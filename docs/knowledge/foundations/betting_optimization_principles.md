# 買い方最適化一般原則

## 1. 目的
- 当たり外れではなく、長期の資金成長と破綻回避を両立する。
- 期待値とリスクを同時に管理する。

## 2. 基本原則
- 確率とオッズを分離して管理する。
- エッジの推定誤差を前提に保守的に配分する。
- 単レース最適より、系列全体の安定性を優先する。

## 3. 意思決定の骨格
- 参加条件:
  - エッジが閾値以上で、流動性条件を満たす。
- 配分条件:
  - 資金に対する上限を持つ。
  - 過剰集中を避ける。
- 停止条件:
  - ドローダウン、連敗、異常相場をトリガーに停止する。

## 4. リスク管理
- 1レース上限、1日上限、同時保有上限を定義する。
- 破滅確率を下げるため、縮小Kellyや固定比率を検討する。
- オッズ変動と約定タイミングのズレを見込む。

## 5. 検証観点
- ROIだけでなく、max drawdownと回復期間を評価する。
- 市場別・時間帯別・人気帯別で分解する。
- 過剰最適化を避けるため、ルールの自由度を制限する。

## 6. よくある失敗
- モデル確率の誤差を無視して過大ベットする。
- 高ROI区間だけを見て全体破綻リスクを見落とす。
- スリッページや締切直前変動を評価に入れない。
- 戦略寿命（エッジ半減期）を管理しない。
