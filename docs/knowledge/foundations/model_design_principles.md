# 学習モデル設計一般原則

## 1. 目的
- モデル単体のスコア最大化ではなく、意思決定品質を最大化する。
- 指標最適化と確率校正を分離して考える。

## 2. 問題設定の原則
- 目的関数の優先順位を明文化する。
- 誤差コストの非対称性を先に定義する。
- ベースラインを固定し、比較可能性を守る。

## 3. データ分割の原則
- 時系列整合を最優先し、未来情報混入を防ぐ。
- 検証は単一分割ではなく複数期間で確認する。
- 分布シフトを前提として評価する。

## 4. モデル化の原則
- まず単純なモデルを基準にする。
- 複雑化は効果と保守性の差分で判断する。
- 校正（Platt/Isotonic等）は本体性能と別に管理する。

## 5. 評価の原則
- 識別性能（AUC）と確率品質（LogLoss/Brier）を併記する。
- 平均値だけでなく、期間別・条件別の劣化を見る。
- 指標差分に実務上の意味があるかを確認する。

## 6. 運用の原則
- 学習・推論の前処理を同一化する。
- 劣化監視指標を事前に決める。
- 再学習トリガーを定量条件で持つ。

## 7. よくある失敗
- AUC改善のみで採用し、校正悪化を見落とす。
- 単一期間の結果を過信する。
- 特徴/前処理のバージョン不整合を放置する。
- 閾値や買い方ルールをモデル変更時に再設計しない。
