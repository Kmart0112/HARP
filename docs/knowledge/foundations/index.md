# 全体知見インデックス

このディレクトリは、実験 run に直接依存しない、中長期で使い回す一般原則を蓄積する場所。

## 使い分け

- `foundations`: 普遍的な方針、原理、意思決定基準
- `patterns`: 実験や調査から繰り返し見えてきた経験則
- `notebook/report`: 実験結果や数値レポート
- MLflow: run、metrics、artifact の証跡

- [betting_optimization_principles.md](betting_optimization_principles.md): 買い方最適化一般原則
- [decision_framework.md](decision_framework.md): 採用/保留/不採用の共通意思決定フレーム
