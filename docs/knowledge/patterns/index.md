# 経験則インデックス

このディレクトリは、実験や調査をまたいで再利用したい「よく効く / 効きにくい」「こう見るとよい」という知見を置く場所。

## 書き方の最小ルール

- 1ファイル 1テーマで書く
- 最初に「今の結論」を短く書く
- どこで効いたか、効かなかったか、次に何を見るかを残す
- 根拠レポートや関連 notebook がある場合はリンクする
- 数値ログではなく、次の判断に使える文章にする

## ドキュメント一覧

- [ability_indicators.md](ability_indicators.md): 能力系指標の変換・レース内相対化
- [target_encoding.md](target_encoding.md): ターゲットエンコーディングの設計・比較手順
- [harp_time_index.md](harp_time_index.md): タイム指数の考え方と特徴量化
- [workout_data_analysis_base.md](workout_data_analysis_base.md): 調教データ分析の基本視点
