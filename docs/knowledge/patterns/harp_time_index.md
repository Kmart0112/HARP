
# 競馬タイム指数まとめ（JRA中心）

## 1. タイム指数とは

タイム指数とは **レースタイムを標準化して馬の能力を比較する指標**である。

競馬のレースタイムは次のような要因に強く影響される。

|要因|内容|
|---|---|
|距離|距離が違えばタイムも変わる|
|馬場状態|重・不良などで大きく遅くなる|
|開催日|同じコースでも日によって速さが違う|
|展開|スローペースだと遅くなる|

そのため **生タイムでは能力比較ができない**。

そこで

```
タイム − 基準タイム
```

の差を指数化して比較する。

代表例

- スピード指数（アメリカ Beyer）
- サンスポ指数
- 競馬ブックタイム指数
- 独自指数（多くの競馬AI）

---

# 2. 基本式

多くのタイム指数は次の形になる。

```
タイム指数
= 基準値 + (基準タイム − レースタイム) × 係数 + 馬場補正
```

例

```
指数 = 80 + (基準タイム − レースタイム) × 10
```

|項目|意味|
|---|---|
基準タイム|その条件で平均的なタイム|
係数|1秒の価値|
馬場補正|当日の馬場の速さ補正|

---

# 3. 基準タイムの作り方

## 方法1：平均

```
基準タイム = 過去レースの平均
```

例

```
東京1600m 良
過去100レース平均
```

メリット

- 実装が簡単
- 安定する

デメリット

- 展開の影響を受ける

---

## 方法2：上位平均

```
基準タイム = 上位○%平均
```

例

```
上位30%平均
```

メリット

- 能力寄りになる

---

## 方法3：回帰モデル

最近のAIではこちらが多い。

```
time ~ course + distance + class + field_size
```

つまり

```
期待タイム = f(条件)
```

---

# 4. 馬場補正

同じコースでも日によって

- 高速馬場
- 重い馬場

があるため **当日の馬場差補正**が必要。

## 方法1：平均差

```
馬場差 = 当日平均 − 基準平均
```

例

基準平均

```
1:34.0
```

当日平均

```
1:33.2
```

差

```
-0.8秒
```

→ 高速馬場

補正

```
補正タイム = 実タイム − 馬場差
```

---

## 方法2：距離別補正

馬場差は距離で異なるため

```
馬場差(distance)
```

で計算する。

---

# 5. 秒→指数変換

1秒の価値は距離によって異なる。

|距離|1秒価値|
|---|---|
1000m|12|
1200m|10|
1600m|8|
2000m|6|
2400m|5|

理由

短距離ほど **タイム差が能力差に直結するため**。

指数化

```
指数 = 80 + (基準タイム − タイム) × 秒価値
```

例

基準

```
1:34.0
```

実タイム

```
1:33.0
```

差

```
1秒
```

価値

```
8
```

指数

```
80 + 1 × 8 = 88
```

---

# 6. 展開補正

タイムは展開に強く影響される。

例

スローペース

```
前半遅い → 全体タイム遅い
```

ハイペース

```
前半速い → 全体タイム速い
```

そのため

- 前半ペース指数
- 上がり指数

などで補正する場合がある。

---

# 7. 統計的意味

タイム指数は本質的には

```
E(time | 条件)
```

からの **残差**をスケール変換したもの。

つまり

```
residual = expected_time − actual_time
```

これを

```
指数 = base + residual × scale
```

としている。

解釈

```
指数 ≈ 条件を統制したパフォーマンス
```

つまり

- コース
- 距離
- 馬場

をコントロールした **能力 proxy**。

---

# 8. 競馬的因果

レースタイムは

```
能力
× 展開
× 馬場
× コース
```

で決まる。

タイム指数は

```
能力 ≈ f(タイム − 環境)
```

として **環境要因を除去する試み**。

ただし

展開が残るため

```
純粋能力 ≠ タイム指数
```

になる。

# 9. AIプロジェクトでの実務実装

## Step1 基準タイム作成

テーブル

```
course
distance
track_condition
baseline_time
```

SQL例

```
avg(time)
group by course,distance
```

---

## Step2 馬場差

```
daily_avg - baseline
```

```
going_diff
```

---

## Step3 補正タイム

```
adjusted_time = race_time - going_diff
```

---

## Step4 タイム指数

```
time_index =
80 + (baseline_time - adjusted_time) * scale(distance)
```

# まとめ

タイム指数は

```
タイム − 環境
```

を指数化したもの。

統計的には

```
条件付き期待値からの残差
```

であり

AIでは

- 能力 proxy
- 強力な特徴量

として機能する。
